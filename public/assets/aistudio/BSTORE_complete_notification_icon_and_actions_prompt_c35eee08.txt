PART 3 — ESTABLISH A SINGLE, EXPLICIT NOTIFICATION CONTRACT

The contract should support, as applicable:

- type: stable machine-readable notification type;
- title: display title;
- body: display text;
- targetId: stable Firestore document ID of the target entity, when relevant;
- targetType: product, order, product_request, promotion, announcement, app_update, or another real existing entity type;
- destination/action: explicit semantic destination or action identifier;
- optional imageUrl for large notification artwork only;
- optional campaign/promotion identifier where relevant;
